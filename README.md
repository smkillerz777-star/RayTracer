# Readme for Week 1

# Ray Tracer
A pygame project in which you can play with light rays , mirror and refracting materials . You can add as many of these as you like , change their sizes and rotate them too. Basically you have full control over how to set up your enviroment

# How to play
 open https://swastik-gupta.itch.io/raytracer \
 download the zip file named Ray_Tracer(Week 1) and extact it \
 run the application

 # Controls
 When the cursor changes from normal to the four head cursor then you are in control of a particular object like mirror, shooter and surface. \
 On clicking mouse button when the cursor light rays are shooted from shooters toward that point \
When cursor is four headed: 
- Left clicking and moving drags the object(mirror,shooter,surface) 
- Scrolling mouse wheel will change angle for spherical mirrors, length for plane mirror, refractive index for surfaces 
- R + mouse wheel scroll will change the radius of spherical mirror
- Right clicking will rotate mirrors

You can add object by:
- pressing f for plane mirrors
- pressing g for spherical mirrors
- pressing h for ray shooters
- pressing j for surfaces

You can delete objects by pressing delete key when the cursor is four headed i.e. near the object
